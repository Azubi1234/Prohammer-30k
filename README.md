# Prohammer 30k

Custom Horus Heresy army lists adapted for **ProHammer Classic** and **New Recruit**.

## Current status

The repository currently contains the core New Recruit game system and a blank `Legiones Astartes` faction catalogue.

### Core system

- Points cost type
- Model profile: WS / BS / S / T / W / I / A / Ld / Sv
- Vehicle profile: BS / Front / Side / Rear
- Walker profile: WS / BS / S / Front / Side / Rear / I / A
- Ranged Weapon profile: Range / S / AP / Type
- Battlefield roles: HQ, Troops, Elites, Fast Attack, Heavy Support, Dedicated Transport, Lords of War
- Standard Age of Darkness Detachment:
  - HQ: 1–2
  - Troops: 2–6
  - Elites: 0–3
  - Fast Attack: 0–3
  - Heavy Support: 0–3

The default roster limit is **2000 points**.
